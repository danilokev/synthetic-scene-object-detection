# Detección de objetos en escenas sintéticas mediante visión por computador

Implementación de un sistema de generación de secuencias de imágenes sintéticas y detección de objetos mediante técnicas de procesamiento de imagen y visión por computador, utilizando Blender y MATLAB.

Proyecto académico correspondiente a la asignatura de Imagen y Vídeo por Computador del Grado en Ingeniería Multimedia.
